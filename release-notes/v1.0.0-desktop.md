## 📦 Installation Guide

### Windows (Installer)

```bash
1. Download MangaKu-1.0.0-Setup.exe
2. Double-click file installer
3. Jika Windows SmartScreen muncul:
   → Klik "More info" → "Run anyway"
4. Ikuti wizard instalasi:
   → Accept license
   → Pilih lokasi install (default: C:\Program Files\MangaKu)
   → Pilih start menu folder
   → Centang "Create desktop shortcut"
   → Klik "Install"
5. Tunggu proses install selesai
6. Klik "Finish" → MangaKu terbuka otomatis
7. Selesai! ✅
```

### Windows (Portable)

```bash
1. Download MangaKu-1.0.0-Portable.exe
2. Copy file ke folder yang diinginkan
   (contoh: C:\Apps\MangaKu\ atau USB drive)
3. Double-click file untuk jalankan
4. Tidak perlu install! ✅

Catatan:
- Data tersimpan di folder yang sama dengan .exe
- Bisa dipindah-pindah tanpa reinstall
- Cocok untuk USB flash drive
```

### Windows (Build dari Source)

```bash
# Prerequisites: Node.js 18+

1. Download source code
2. Extract ke folder yang diinginkan
3. Buka Command Prompt di folder project
4. Jalankan:
   setup-windows.bat
5. Tunggu 5-10 menit
6. Jalankan:
   run-windows.bat
7. Aplikasi terbuka! ✅

Untuk buat installer:
   build-windows.bat
```

### macOS

```bash
1. Download MangaKu-1.0.0.dmg
2. Double-click file .dmg
3. Drag MangaKu ke Applications folder
4. Eject disk image
5. Buka Applications → MangaKu
6. Jika ada warning "from unidentified developer":
   → System Preferences → Security & Privacy
   → Klik "Open Anyway"
7. Selesai! ✅
```

### Linux (AppImage)

```bash
1. Download MangaKu-1.0.0.AppImage
2. Buka terminal di folder download
3. Jalankan:
   chmod +x MangaKu-1.0.0.AppImage
   ./MangaKu-1.0.0.AppImage
4. (Opsional) Buat shortcut:
   cp MangaKu-1.0.0.AppImage ~/.local/bin/mangaku
5. Selesai! ✅
```

### Linux (Debian/Ubuntu)

```bash
1. Download mangaku_1.0.0_amd64.deb
2. Buka terminal:
   sudo dpkg -i mangaku_1.0.0_amd64.deb
3. Jika ada error dependencies:
   sudo apt-get install -f
4. Launch dari applications menu
5. Selesai! ✅

Uninstall:
   sudo dpkg -r mangaku
```

## 🐛 Known Issues & Limitations

### 1. App Size
**Issue**: Installer cukup besar (~80MB)  
**Cause**: Bundling Chromium + Node.js  
**Impact**: Download lama, disk usage tinggi  
**Workaround**: Gunakan versi portable  
**Status**: 🟡 Will optimize in v1.1.0

### 2. Startup Time
**Issue**: Cold start 3-5 detik  
**Cause**: Electron initialization  
**Impact**: Tidak instant seperti native app  
**Workaround**: Biarkan app running  
**Status**: 🟡 Electron limitation

### 3. Memory Usage
**Issue**: Memory usage 100-300MB  
**Cause**: Chromium engine  
**Impact**: Tidak cocok untuk sistem dengan RAM < 2GB  
**Workaround**: Tutup window yang tidak dipakai  
**Status**: 🟡 Electron limitation

### 4. Windows SmartScreen
**Issue**: Warning saat first run  
**Cause**: App tidak signed dengan certificate  
**Impact**: User perlu klik "Run anyway"  
**Workaround**: Klik "More info" → "Run anyway"  
**Status**: 🟡 Will sign in future release

### 5. macOS Gatekeeper
**Issue**: Warning "unidentified developer"  
**Cause**: App tidak signed dengan Apple certificate  
**Impact**: User perlu allow di System Preferences  
**Workaround**: System Preferences → Security → Open Anyway  
**Status**: 🟡 Will sign in future release

### 6. Linux Dependencies
**Issue**: Beberapa distro butuh dependencies manual  
**Cause**: Different package managers  
**Impact**: App mungkin tidak jalan di beberapa distro  
**Workaround**: Install dependencies yang dibutuhkan  
**Status**: 🟡 Will improve packaging

### 7. Auto-Update
**Issue**: Auto-update belum implemented  
**Cause**: Butuh update server  
**Impact**: User harus download manual  
**Workaround**: Check GitHub releases  
**Status**: 🟡 Coming in v1.1.0

## 🛠️ Development & Build

### Build dari Source

```bash
# Prerequisites
- Node.js 18+
- Git
- (Windows) Visual Studio Build Tools
- (macOS) Xcode Command Line Tools
- (Linux) build-essential

# Steps
git clone https://github.com/USERNAME/mangaku.git
cd mangaku
npm install
npm run build

# Run in development
npx electron electron/main.js

# Build installer
# Windows
npx electron-builder --win --config electron-builder.yml

# macOS
npx electron-builder --mac --config electron-builder.yml

npx electron-builder --linux --config electron-builder.yml
```
