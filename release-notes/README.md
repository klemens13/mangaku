## 🚀 Quick Start

### Web/PWA (2 Menit)
```bash
1. Deploy folder dist/ ke Netlify/Vercel
2. Buka URL di browser
3. Install sebagai PWA
4. Selesai! ✅
```

### Desktop Windows (5 Menit)
```bash
1. Install Node.js dari nodejs.org
2. Double-click: setup-windows.bat
3. Double-click: run-windows.bat
4. Selesai! ✅
```

## 🔐 Verify Downloads

Semua file download memiliki SHA256 checksum untuk verifikasi integritas.

**Cara verifikasi:**

Windows (PowerShell):
```powershell
Get-FileHash MangaKu-1.0.0-Setup.exe -Algorithm SHA256
```

macOS/Linux:
```bash
shasum -a 256 MangaKu-1.0.0.dmg
```

Compare dengan checksum di release notes masing-masing versi.
