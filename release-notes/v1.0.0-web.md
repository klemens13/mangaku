```bash

3. Buka https://app.netlify.com
4. Drag & drop folder dist/
5. Dapat URL: https://your-app.netlify.app
```

#### 2. Vercel
```bash
1. Install Vercel CLI: npm i -g vercel
2. Jalankan: vercel
3. Follow prompts
4. Deploy otomatis!
```

#### 3. GitHub Pages
```bash
1. Push folder dist/ ke branch gh-pages
2. Enable GitHub Pages di Settings
3. URL: https://username.github.io/repo-name
```

#### 4. Manual Hosting
```bash
1. Upload isi folder dist/ ke web server
2. Pastikan HTTPS aktif (WAJIB untuk PWA)
3. Konfigurasi MIME types untuk .webmanifest
```

## 🐛 Known Issues & Limitations

### 1. Image Loading
**Issue**: Gambar manga menggunakan placeholder (picsum.photos)  
**Impact**: Gambar mungkin lambat atau tidak tersedia  
**Workaround**: Download chapter untuk akses offline  
**Status**: 🟡 Will fix in v1.1.0

### 2. iOS PWA Limitations
**Issue**: Beberapa fitur PWA tidak bekerja di iOS Safari  
**Details**: 
- Download chapter tidak persisten setelah restart
- Background sync tidak supported
- Push notifications limited  
**Workaround**: Gunakan Chrome di iOS  
**Status**: 🟡 Apple limitation

### 3. Storage Limits
**Issue**: Browser memiliki limit storage  
**Details**: 
- Chrome: ~10% of disk
- Safari: ~50MB
- Firefox: ~10% of disk  
**Workaround**: Hapus chapter yang sudah dibaca  
**Status**: 🟡 Browser limitation

### 4. Offline Images
**Issue**: Cache API tidak selalu reliable  
**Details**: Beberapa browser mungkin clear cache  
**Workaround**: Download ulang jika perlu  
**Status**: 🟡 Will improve in v1.1.0
